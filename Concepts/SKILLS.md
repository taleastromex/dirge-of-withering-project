# Skills

Атрибуты и производные характеристики.  
**Этап 3** почти не качает этот лист — фиксируем роли статов и якоря, чтобы ребаланс урона/FILTH не разъехался с будущей прокачкой.  
Поинты / уровни / экип — **этап 4+**.

## Слои (важно не смешивать)

| Слой | Что это | Прокачка |
|------|---------|----------|
| Свойства (атрибуты) | Сила, Телосложение, Ловкость, Интеллект | этап 4+ |
| Производные | HP, урон, скорость… | из атрибутов / экипа |
| Ресурсы | **Filth** (боевая шкала 0…Max) | только геймплей (удары, decay, алтарь) |
| Приобретённые | **Filth Level** (постоянный след) | сюжет / мутации / выбор; **не** поинтами |
| Соц. навыки | Убеждение, Запугивание | этап 4+ |
| Спец-атаки | Высвобождение Ихора, Магия крови | Высвобождение — этап 3; магия крови — 4+ |

## Свойства

Каждый атрибут — **один primary**, чтобы билд не схлопывался в Strength+Con.

| Свойство | Primary | Secondary (слабо) |
|----------|---------|-------------------|
| **Сила** | физ. база `N`, Запугивание, сила Высвобождения | чуть скорости |
| **Телосложение** | Max HP, стойкость | — (не даёт базовый урон) |
| **Ловкость** | скорость передвижения, Скрытность | позже crit / dodge |
| **Интеллект** | маг. атака, Убеждение | Магия крови (4+) |

## Производные характеристики

| Характеристика | Влияет | Этап 3 |
|----------------|--------|--------|
| Базовый урон `N` | **Сила** (primary) | фиксированный якорь, см. [DAMAGE.md](./DAMAGE.md) |
| Запас здоровья | Телосложение | фиксировано **100** |
| Скорость передвижения | Ловкость (+ слабый вклад Силы) | текущий MoveSpeed + ступени FILTH |
| Скрытность | Ловкость | не используется в срезе |
| Магическая атака | Интеллект | нет у игрока в срезе |
| Filth (ресурс) | не атрибут | gain / decay / алтарь по DAMAGE |

## Социальные (этап 4+)

- **Убеждение** — Интеллект, Ловкость  
- **Запугивание** — Интеллект, Сила  

На этапе 3 не балансируем и не вешаем на бой.

## Приобретённые (не прокачиваются поинтами)

### Filth Level

Постоянный «нулевой» уровень заражения Ихором (след на теле / репутация у Церкви).

- **Не** равен боевой шкале Filth.
- Боевой Filth растёт и падает в стычке; Filth Level меняется редко (мутации, сюжет, долгий OVERLOAD — уточним в 4.x).
- Church Knight и подобные смотрят прежде всего на **Filth Level** (и явные мутации), а не на каждый пик боевой шкалы в данже.
- На этапе 3: `Filth Level = 0` у игрока; логику агро Церкви не внедряем.

## Спец-атаки

### Высвобождение Ихора (этап 3)

- Влияет: текущий **Filth%** (ступени урона), **Сила** (через базу `N`).
- Формулы, soft-cap FILTH на себя, таблица ступеней — в [DAMAGE.md](./DAMAGE.md).
- В билде = текущий heavy (ПКМ / hold — как уже заведено); цифры подтянуть к якорю этапа 3.

### Магия крови (этап 4+)

- Влияет: Магическая атака, Сила, Интеллект.
- Отдельный маг/ихор pipeline, не трогаем в ребалансе.

## Якорь этапа 3 (без дерева прокачки)

Пока атрибуты не качаются, считаем «виртуальный» стартовый лист:

```text
Сила           = baseline → N = 24
Телосложение   = baseline → Max HP = 100
Ловкость       = baseline → текущая скорость среза
Интеллект      = baseline → маг. атак нет
Filth          = 0…100 (бой)
Filth Level    = 0
```

Любой будущий `+1 Сила → +X к N` описываем только когда появится прокачка; до этого крутим только `N`, пороги и drain из DAMAGE.

## Вне скоупа этапа 3

- Очки характеристик, уровни, требования экипа.
- Убеждение / Запугивание / Скрытность в геймплее.
- Магия крови, дисциплины, смена оружия из инвентаря.
- Рост Filth Level и реакция нейтралов.
