# Damage

Канон урона и скверны. **Этап 3 (ребаланс)** опирается на секции ниже до пометки «Этап 4+».  
Числа — целевые для тюнинга на `TestWorld` / срезе; код подтягиваем к этому документу, а не наоборот.

## Типы урона

### Физический урон

Обычный удар оружием / телом. Режется физическим сопротивлением цели.  
На этапе 3 это основной тип игрока (zweihänder).

### Магический урон

Сверхъестественный урон (маги, часть нежити). Может идти отдельно или вместе с физическим.  
Игнорирует физ. сопротивление. **Полный pipeline — этап 4+** (в срезе у игрока нет маг-атак).

### Урон от Ихора

Гибридное дополнение к физике Отрекшегося и искажённых.  
Почти никто не имеет сопротивления, кроме **Relict** и **Ichor Explorer Cultist** (у них отдельный ichor resist).  
Базовая доля: `ichor = 0.5 × N`, где `N` — физ. база удара до множителей скверны.

## Формула удара (этап 3)

Обозначения:

- `N` — база физического урона атаки (light или Высвобождение до бонусов скверны)
- `Filth%` — текущая боевая шкала `Filth / MaxFilth`
- `filth_bonus` — ступень из таблицы ниже (только **физ** часть)
- `resist_phys` / `resist_ichor` — сопротивления цели (0…1)

```text
phys  = N × (1 + filth_bonus)
ichor = 0.5 × N                    # без filth_bonus (ихор не «удваивается» от шкалы)
raw   = phys + ichor

taken_phys  = phys  × (1 - resist_phys)  × vulnerability
taken_ichor = ichor × (1 - resist_ichor) × vulnerability
taken       = taken_phys + taken_ichor
```

На этапе 3 у рядовых целей `resist_ichor = 0`.  
Уязвимости категорий NPC (Дисциплины и т.п.) — множитель `vulnerability`; в срезе можно держать `1.0`, пока дисциплин нет.

## Атаки игрока (этап 3)

| Атака | Физ. база `N` | Ихор | FILTH на себя | Примечание |
|-------|---------------|------|---------------|------------|
| Light (ЛКМ) | `N` | `0.5×N` | 0 | Быстрый удар |
| Высвобождение Ихора (heavy) | `2×N` | `0.5×(2×N)` = `N` | см. soft-cap | Медленнее, риск/награда |

Стартовый якорь (паритет [Knight](./NPCs/Neutral/humans/knight.md): HP 180, урон ~60 raw):

| Параметр | Цель этапа 3 | В билде |
|----------|-------------:|--------:|
| Player Max HP | **180** | 180 |
| Player PhysResist | **20%** | 20% |
| Light `N` | **40** | 40 |
| Raw light (без resist цели) | `N + 0.5N` = **60** | 60 |
| Высвобождение база | `2×N` (=80) | 80 |
| Max Filth | 100 | 100 |
| Порог HIGH | **50%** | 50% |

Срез NPC (карточки): Ash Walker **160 / 40 / 25%**, Ichor Beast **250 / 60 / 35%**.

### Soft-cap FILTH от Высвобождения

```text
filth_self = min(0.5 × N_release, 20)
```

где `N_release = 2×N` (база heavy до бонусов).  
При `N=40` → `min(40, 20) = 20` FILTH за удар.

## Множитель скверны (ступени)

Таблица действует **на весь исходящий физ. урон игрока** (light и Высвобождение).  
Отдельных старых бонусов HIGH/OVERLOAD вроде +35% / +25% **не суммируем** — одна кривая.

| Filth% | `filth_bonus` | Итог к физ (`×`) |
|-------:|-------------:|-----------------:|
| &lt; 50% | 0.00 | ×1.00 |
| ≥ 50% | 0.25 | ×1.25 |
| ≥ 75% | 0.50 | ×1.50 |
| ≥ 90% | 0.75 | ×1.75 |
| 100% (OVERLOAD) | 1.00 | ×2.00 |

Скорость (этап 3, упрощённо): `≥50% → +10%`, `≥75% → +15%`, `100% → +20%` move speed.  
Тюнить после урона; главное — не вернуться к двойному стеку множителей.

## OVERLOAD

При `Filth ≥ MaxFilth`:

- физ. урон по ступени ×2.00;
- **drain 6 HP/с** (не бафф атаки — наказание);
- визуал/SFX перегрузки как сейчас;
- сброс только алтарём / будущими расходниками (этап 4+).

## Входящий FILTH (этап 3)

| Источник | Формула / значение |
|----------|--------------------|
| Удар искажённого Пеплом | `filth_gain = 0.5 × damage_taken` (после resist игрока, если появится) |
| Высвобождение (на себя) | soft-cap выше |
| Удар обычного человека | 0 FILTH |
| Алтарь | burst при входе + cleanse/с (тюнинг к кривой) |

Лужа ихора (опционально в 3.x): `+3…5 FILTH/с` стоя в зоне — только если базовая кривая от боя уже стабильна.

## Цель ребаланса (DoD этапа 3)

На срезе / `TestWorld` без новых систем:

1. **Чистый прогон** (Filth низкий) — fair TTK vs Ash Walker и Ichor Beast.
2. **На HIGH (≥50%)** — заметно сильнее, игрок сам решает держаться у порога.
3. **OVERLOAD** — короткий burst силы, затем давление 6 HP/с; алтарь = осмысленный сейв.
4. HUD читает состояние: `FILTH` + ступень (`×1.25` / OVERLOAD), без загадки.

Вне скоупа этапа 3: инвентарь, дисциплины, полный маг-pipeline, прокачка атрибутов, новые враги.

## Этап 4+ (не трогаем в ребалансе)

- Раздельные resist-таблицы по всем NPC из `Concepts/NPCs/`.
- Магия крови как отдельная атака с маг. уроном.
- Живое оружие, кормление, стойки.
