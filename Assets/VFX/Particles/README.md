# Particle textures (reusable)

Soft billboard sprites for ash / ember / ground smoke.

| File | Use |
|------|-----|
| `ash_soft.png` | Falling cathedral ash |
| `ash_ember.png` | Warm altar embers |
| `smoke_soft.png` | Low smoke blankets |

Generated for Dirge of Withering vertical slice; free to reuse in other VFX.
